# Mission Impossible 🕵️‍♂️ (Programming Fundamentals)

A 2D top-down stealth grid-based game built in **C++** using the **SFML** library. Navigate through procedurally generated layouts, collect keys, unlock doors, evade moving enemies, and acquire weapons to clear your path.

## Features

- **Grid-Based Movement:** Precise directional movement mapped to an invisible matrix.
- **Dynamic Entities:** Intelligent enemies that patrol vertically or horizontally.
- **Inventory System:** Collect and manage keys to open locked doors.
- **Combat Mechanics:** Pick up and use weapons to eliminate obstacles or enemies.
- **Score Tracking:** Local high-score tracking persisted across sessions.
- **Dual Controls:** Playable with either `W A S D` or `Arrow Keys`.

## Prerequisites

- C++ Compiler (GCC / MinGW)
- SFML 2.6.x (Included/configured via `run.bat`)

## How to Play

1. Run `run.bat` to compile and launch the game.
2. Use `WASD` or `Arrow Keys` to move.
3. Collect keys to unlock color-coded doors.
4. Avoid enemies unless you have a weapon.
5. Reach the extraction point to win!
